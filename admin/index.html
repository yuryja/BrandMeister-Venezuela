Ajustes & Base de Datos MySQL

DBngin / DBng / cPanel

Conexión con Base de Datos MySQL

Base de Datos: bmvenezuela
Servidor / Host: 127.0.0.1 (o localhost)
Puerto: 3306
Codificación: utf8mb4_unicode_ci
Esquema SQL: Descargar schema.sql ↗

Instrucciones para importar en DBngin / DBng:

  1. Abre tu cliente de base de datos preferido (DBngin, DBng, TablePlus, DBeaver o phpMyAdmin).
  2. Crea una nueva base de datos llamada bmvenezuela (o importa directamente el archivo schema.sql que se encuentra en la raíz del proyecto).
  3. Las tablas bm_users, bm_posts, bm_site_settings y bm_activity_logs se crearán automáticamente con los datos iniciales de BrandMeister Venezuela.
  4. El conector PHP en public/api/config.php se conectará de manera inmediata y transparente.
